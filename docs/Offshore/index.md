# Offshore Wind Turbines

This section offers documentation of the offshore wind turbines included in this database.

The National Renewable Energy Laboratory provides an overview of the offshore wind market in
Offshore Wind Technologies Market Reports and Data Updates.

2019 Data Update: https://www.nrel.gov/docs/fy21osti/77411.pdf

The following distributed wind turbines have been made publicly available. Each turbine will
have a link to its power curve file in the repository, a reference, power and Cp curve plots,
and any other available data. Please note some turbines do not conain all the information, and
will therefore be missing those data points.
